# memopt: підбір порогів методу рухомої епідемії (MEM) для захворюваності на ГРВІ

Версія 0.3. Працює поверх пакета `mem` (Vega, Lozano та ін.), сам `mem` не змінює. Ліцензія GPL (>= 2), як у `mem`.

## Що робить

Для кожної території (область, райони, міста, громади) програма підбирає кут нахилу методу MEM і розраховує чотири пороги: епідемічний, середній, високий, дуже високий. Кут обирається за результатами перевірки на відкладених сезонах: мінімум суми хибних сигналів і запізнення. Для малих територій (громад) поріг складається з власного порогу і порогу території-еталона з коефіцієнтом, з вагою, що залежить від кількості випадків. Окремо виконуються діагностики (пропорційність, багато хвиль), вплив сезонів і стабільність порогів.

## Вхідні дані

1. Ряди захворюваності: аркуші Excel (перша колонка тижні, решта сезони), один формат для всіх територій.
2. Перелік територій: CSV з колонками `id`, `name`, `kind` (`main` або `small`), `file`, `sheet`, для малих ще `population` і `reference_id`.
3. `config.json`.

Якщо малих територій немає, рахуються лише основні території. Докладно: розділ 3 посібника.

## Запуск

```
Rscript run_optimizer.R
```

Потрібні R 4.2 або новіший і пакети `mem` (не старіший за 2.18), `readxl`, `jsonlite`, `openxlsx`, `dplyr`, `tidyr` (`install_packages.R` ставить їх). Для побудови документів потрібен Python 3.10 або новіший з пакетами з `requirements.txt`.

## Перенесення на інший комп'ютер

Папка самодостатня: усі шляхи в коді відносні до неї, ряди основних територій лежать у `input/series`, ряди громад у `input/hromadas.xlsx`, `config.json` посилається на `input/series`. Для користувача без R-досвіду є файли `1_ЧИТАТИ_СПОЧАТКУ.txt`, `2_Встановити_пакети.bat`, `3_Розрахувати_пороги.bat` і `4_Зібрати_документи.bat`; `_find_r.cmd` знаходить Rscript через реєстр або Program Files. Папка `memopt_ЦГЗ` поряд це копія для передачі без службових і чорнових файлів (без чернетки статті, експериментальних конфігів, книг для гугл-таблиці).
