# memopt: підбір порогів методу рухомої епідемії (MEM) для захворюваності на ГРВІ

Версія 0.4. Працює поверх пакета `mem` (Vega, Lozano та ін.), сам `mem` не змінює. Ліцензія GPL (>= 2), як у `mem`.

## Що робить

Для кожної території (область, райони, райони без міста-центру, міста, громади) програма розраховує чотири пороги MEM: епідемічний, середній, високий і дуже високий.

1. **Набір сезонів** для кожної основної території добирається автоматично. Основа це всі сезони нинішнього періоду (`season_selection.era_start`, у нас з 2023/2024), до неї по одному додаються старші сезони. Кожен набір перевіряється на контрольних сезонах (сезони нинішнього періоду, крім `not_validation`): контрольний сезон відкладається, поріг будується за рештою, рахуються хибні сигнали і тижні запізнення. Обирається набір з найменшою сумарною помилкою; при рівності вищий MCC на контрольних сезонах, далі набір з 5 і більше сезонів, далі коротший. Довший набір допускається, лише якщо його MCC не нижчий за MCC основи, погіршений на один помилковий тиждень (`guard_weeks`).
2. **Межі епідемії** в контрольних сезонах визначає `memtiming` стандартним кутом 2,8 окремо для кожної території. Сезон, пік якого нижчий за епідемічний поріг, побудований за іншими сезонами території, вважається сезоном без епідемії: у ньому рахуються лише хибні сигнали.
3. **Кут нахилу** для кожного набору перебирається від 2,0 до 4,0 з кроком 0,25 і обирається за тією самою сумарною помилкою з обмеженнями (MCC більший за 0, епідемічний поріг нижчий за середній, межа стабільності 20%).
4. **Малі території (громади)**: поріг є зваженим поєднанням власного порогу і порогу території-еталона, перерахованого через коефіцієнт k; вага власного порогу зростає з кількістю випадків. Кут власного порогу береться найвищий не вище кута групи, при якому епідемічний поріг нижчий за середній, інакше власний поріг непридатний.
5. **Діагностики**: вплив сезонів, стабільність наборів, пропорційність, багато хвиль, перевірка вхідних даних, порівняння з попереднім запуском (позначка, якщо зміна більша за найбільший вплив одного сезону).

Сезони з пандемічним грипом, омікроном і масовою міграцією (2015/2016, 2016/2017, 2021/2022, 2022/2023) відсікаються автоматично. Користувач може додатково виключити сезон з причиною для всіх територій (`exclude_seasons`) або для однієї (`exclude_territory_seasons`).

## Запуск

```
Rscript run_optimizer.R
python build_all.py
```

Потрібні R 4.2 або новіший і пакети `mem` (не старіший за 2.18), `readxl`, `jsonlite`, `openxlsx`, `dplyr`, `tidyr` (`install_packages.R` ставить їх). Для документів потрібен Python 3.10 або новіший з пакетами з `requirements.txt`.

## Перенесення на інший комп'ютер

Папка самодостатня: усі шляхи в коді відносні до неї. Для користувача без досвіду R є `1_ЧИТАТИ_СПОЧАТКУ.txt`, `2_Встановити_пакети.bat`, `3_Розрахувати_пороги.bat` і `4_Зібрати_документи.bat`; `_find_r.cmd` знаходить Rscript через реєстр або Program Files.
