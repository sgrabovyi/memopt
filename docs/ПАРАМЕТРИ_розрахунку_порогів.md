## 2. Модель MEM

Пакет mem для R, функція memmodel з такими налаштуваннями: епідемічний період за методом нахилу (i.method = 2) з кутом δ, який добирається окремо для кожної основної території (розділ 3); епідемічний поріг як верхня межа одностороннього 95% довірчого інтервалу для n = 30 поділити на кількість сезонів найвищих доепідемічних значень (i.type.threshold = 5, i.tails.threshold = 1, i.n.max = −1); пороги інтенсивності з 30 поділити на кількість сезонів найвищих епідемічних значень у логарифмічній шкалі (i.type.intensity = 6) на рівнях 40%, 90% і 97,5% односторонніх інтервалів, що дає середній, високий і дуже високий пороги; середня крива за інтервалом 95% (i.type.curve = 2, i.level.curve = 0,95), інші показники за i.type.other = 3 на рівні 0,95, центрування i.centering = −1.

## 3. Добір кута нахилу для основних територій

Кут δ перебирали від 2 до 4 з кроком 0,25. Для кожного кута і кожного набору сезонів поріг перевіряли на контрольних сезонах (сезони нинішнього періоду, крім 2023/2024): контрольний сезон відкладали, поріг будували за рештою сезонів набору і порівнювали з межами епідемії, визначеними за даними самого сезону функцією memtiming пакета mem при стандартному куті 2,8. Сезон, пік якого нижчий за епідемічний поріг, побудований тим самим кутом за іншими сезонами території, вважається сезоном без епідемії, і в ньому рахуються лише хибні сигнали. Критерій вибору: найменша сумарна помилка, тобто сума хибних сигналів і тижнів запізнення з вагами 1 : 1. Додаткові умови: коефіцієнт кореляції Метьюза більший за нуль, епідемічний поріг нижчий за середній, і обмеження стабільності: рухаючись від кута 2,8 донизу, зупинялись перед кроком, на якому епідемічний поріг падає більш ніж на 20% (стовпець «Нижня межа за стабільністю»). ## 4. Малі території (громади)

Спосіб: mixture (часткове об'єднання власного порогу громади з порогом району-еталона, помноженим на коефіцієнт k = сума випадків громади поділити на суму випадків еталона за спільні тижні). Вага власного порогу w = n / (n + c*), де n медіана випадків громади на тиждень; c* дібрано за даними всіх громад. Групи за медіаною випадків на тиждень: надійні дані від 14, обмежені від 6, нижче ненадійні. Кут нахилу для власного порогу громади спершу обирався за групою, а не для кожної громади окремо: обмежені дані 3; надійні дані 3; ненадійні дані 3. Кут групи вихідний: для кожної громади береться найвищий кут, не вищий за кут групи, при якому її епідемічний поріг нижчий за середній; якщо такого кута немає, власний поріг громади непридатний (вага 0), і поріг будується лише за еталоном з коефіцієнтом. Запасне правило: якщо епідемічний поріг суміші все ж виявлявся не нижчим за середній, його знижували до 95% середнього (позначено в таблиці 2; у нинішньому розрахунку не спрацювало ні разу).

Очищення початку сезону: увімкнено для територій «small»: значення перших тижнів, що перевищують медіану наступних 8 тижнів більш ніж на 2,5 MAD, прибираються перед побудовою порогу. Прибрані тижні перелічено в таблиці 3.
